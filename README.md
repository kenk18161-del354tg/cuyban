# BlockAll Bot

Estructura modular preparada para GitHub + Railway + PostgreSQL.

Las credenciales reales deben ir exclusivamente en Railway Variables:
BOT_TOKEN, OWNER_ID, GROUP_ID, DATABASE_URL y demás secretos necesarios.

La imagen principal va en assets/imagen_principal.jpg y no se usa en /start, /cmds, /me ni /buy.

Servicios y operaciones reales de banca, telecomunicaciones o IMEI deben conectarse únicamente mediante sistemas/proveedores autorizados y confirmación verificable.
